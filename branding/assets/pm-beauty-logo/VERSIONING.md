# Logo versioning

User instruction, 18.10.2026: never delete or overwrite logo revisions. Create new versions in chronological order: v1, v2, v3, etc.

The five pre-existing revisions have been copied into `versions/v1/` through `versions/v5/` without changing their originals. The Italiana revision with a flat-topped E centre stem is `versions/v6/`.

For every subsequent change, create the next unused `versions/vN/` directory. Keep its SVGs, preview, source and notes together. Never regenerate into an existing version or replace the older top-level logo files. Scripts for new versions must refuse to overwrite output files. The highest version number is the newest revision, not necessarily an approved design.
