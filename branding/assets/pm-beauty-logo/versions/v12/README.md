# PM monogram v12: centered detached stem

This is the already approved v10 drawing, with the main contour unchanged. The only geometry change is a 70 SVG-unit downward translation of the separate left P stem. The website keeps v10's 130% header and 120% footer weights. The writing animation moves the stem mask by the same amount, so the animated and final logo match.

`base-v10.json` is a snapshot of the archived v10 source. `make_logo.py` produces the two transparent SVGs and `animation-data.json` and refuses to overwrite existing files. `preview.html` shows both website sizes on the current cream color.
