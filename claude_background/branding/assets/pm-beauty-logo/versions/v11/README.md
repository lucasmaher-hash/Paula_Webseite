# PM Monogram v11

Reconstructed from Lucas's two 21 October ink references. The reference without the detached left stem supplies the main proportions; the second supplies that separate stem. The main contour is normalized to a 1600 × 1000 viewBox with the principal top and bottom extrema aligned to an intended rectangle. The upper-left hook and lower-right serif remain outside it.

The stem is moved 30 SVG units down from its traced position so it sits optically between the upper horizontal segment and lower diagonal. Both variants are filled vector paths with transparent backgrounds, not embedded raster images. The earlier v10 is a separate construction from the first pencil sketch and remains archived.

- `pm-monogram-with-stem.svg`: website variant; Figma component `38:7`.
- `pm-monogram-without-stem.svg`: alternate; Figma component `38:10`.
- `make_logo.py`: reproducible source script that refuses to overwrite an existing SVG or preview.
- `write_mask.py` and `animation-centerline.json`: control points for the website writing animation, aligned to this outline.
- `reference-*.jpeg`: the supplied source photos.
