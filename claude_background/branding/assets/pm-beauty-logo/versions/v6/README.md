# PM Beauty · v6

Created 18.10.2026. Font: Italiana Regular, converted to editable vector outlines. Capital height: 100 units, matching the previous lettering. The existing B +8% and A −6% width adjustments are retained relative to the new font.

The custom E retains v5's enlarged dimensions, bar weight, thin centre stem and downward serifs. Its centre stem now ends with a flat cap at the same height; the top serif and its flared transitions have been removed.

Spacing is recalculated for Italiana so the E stays exactly on the centre of the visible wordmark. Transparent SVGs: `pm-beauty-black.svg`, `pm-beauty-white.svg`; separate symbol: `pm-beauty-E.svg`. `pm-beauty-preview.png` shows the white version on a dark background.

This is a new immutable revision. All earlier files remain intact. Future edits go in v7 or the next unused version folder.

Original font and SIL Open Font License are included under `source/`. Source: https://github.com/google/fonts/tree/main/ofl/italiana
